순서대로 통합해야 하며 각 PR은 앞 단계의 변경을 포함한 브랜치를 대상으로 한다.

## 확인된 결과

- `npm test`, `npm run build`, `npm run verify:site` 통과.
- 동일 시드 3년 플레이는 동일 상태로 재현. 30일·90일·1년·3년·10년까지 진행·저장·불러오기, 거래 ID 유일성, 자금 비음수, NPC ID 보존 검증.
- 승인·런타임 적격 이미지와 동일 AP ID·성별·나이대·정본 키/몸무게가 일치해야 전신 표시. 현재 저장소의 정적 카탈로그는 빈 상태다. 원격 API에는 정본 신체 수치가 노출되지 않아 실 이미지의 물리 일치 여부는 검증할 수 없으며 전신 표시는 보류된다.
- Playwright Chromium 320/375/390/430px 및 WebKit iPhone 자동화가 GitHub Actions 실행 #145에서 통과. 홈·인물·경제·사건·결과 화면 캡처가 아티팩트에 생성됐다. 로컬 환경에는 브라우저 바이너리가 없으며 실제 iPhone Safari의 하드웨어 노치·키보드·홈바 확인은 남아 있다.

## 남은 우선순위

1. 실제 iPhone Safari에서 하드웨어 노치·키보드·홈바와 모달을 확인하고, 문제가 있으면 해당 UI 브랜치에서 수정.
2. 공식 이미지 DB가 검수된 정본 키·몸무게를 카탈로그에 제공하도록 계약 확장. 숫자와 승인 근거를 받기 전에는 게임과의 일치 인증 불가.
3. 10년 플레이의 선택 다양성·경제 밸런스를 실제 사람의 플레이 데이터로 조정. 현재 금액은 게임용 가정이며 통계 근거값과 연결되지 않았다.
4. 월별 부채 연체·이자·주거 계약 같은 상세 경제 규칙과 NPC의 직업별 현실 분포를 별도 데이터 계약으로 확장.

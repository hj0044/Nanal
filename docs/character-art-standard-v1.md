# Nanal 반실사 캐릭터 제작 표준 v1.0

> **상태:** 제작 규격 확정 / 실제 16개 배포용 에셋 미승인. 2026-10-22.
> 비용 원칙: 무료 제작 도구 위주. 유료 생성 API, 실시간 이미지 생성 비용, 유료 배포는 필수 전제가 아니다.

## 1. 품질 원칙

- Nanal은 현대 한국의 일상형 인생 시뮬레이션. 인물은 극적인 미남·미녀보다 자연스러운 인상과 넓은 외모 분포를 갖는다.
- **반실사 디지털 페인팅**(사진/실사 합성 아님), 현실적인 얼굴 비율과 섬세한 머리카락, 부드러운 피부 명암, 균일한 외곽 처리.
- 모든 인물이 같은 카메라와 광원 규칙을 사용한다: 좌전방의 부드러운 확산광, 낮은 대비, 단색 중성 임시 배경 또는 RGBA 투명.
- 기준 표정은 중립~아주 옅은 미소. 감정 표정은 후속 별도 레이어.
- 보정 전 소스는 원본 PNG RGBA, 색공간 sRGB. 최종 공개용은 승인 WebP. 제자리 합성을 위한 캔버스와 기준 좌표는 마스터에 고정.

## 2. 두 가지 뷰

| 요소 | 얼굴 / 상반신 (bust) | 전신 (full) |
|---|---|---|
| 마스터 | 1024×1024 RGBA | 1024×1536 RGBA |
| 카메라 | 정면 기준 약 10–15° 측면 | 정면 기준 약 5–10° 측면 |
| 시선 | 카메라 근처 | 카메라 근처 |
| 포즈 | 가슴 위, 어깨 이완, 얼굴/목 고정 | 자연스러운 정자세, 손 보임, 양발 화면에 포함 |
| 크롭 | 헤어 여백 충분히 확보 | 머리~신발과 안전 여백 |
| 사용처 | NPC 목록·대화·관계·이벤트 | 주인공/인물 상세·의상·직업 연출 |

**주의:** 얼굴과 전신 시점이 약간 다르므로 동일한 원본 헤어/의상 파츠를 단순 확대하여 공유하지 않는다. 두 뷰가 공유하는 것은 외형 **데이터 ID**, 캐릭터 정체성과 디자인이며, 각 뷰의 승인 에셋은 별도 제작한다.

## 3. 파츠 계약

- 공통 순서: 뒷머리 → 몸 → 의상 뒤 → 의상 본체 → 고정 얼굴 → 앞머리 → 의상 앞깃 → 액세서리 → 접촉 그림자.
- 원본 얼굴의 눈·코·입·중심형태를 변경하는 헤어/의상 합성은 불허한다. 중심 얼굴 마스크에서 **합성 전후 RGBA 픽셀 일치**를 시험한다.
- 헤어는 실제 실루엣과 길이가 다른 두 종류. 단순 색조 변경 금지. 뒷머리/앞머리/귀 가림/그림자 필요.
- 의상은 실제 디자인이 다른 두 종류. 상체 체형별 재제작, 목깃/목/어깨/팔 충돌 검수.
- 피부색·머리색·옷감색·광원이 일치해야 하며, 바깥 배경으로 오염된 불투명 픽셀은 불허.
- 성인 남/녀 템플릿부터 개발하되, 중년·고령·어린이는 각 신체/두상 계열로 분리. 성별 판단을 이미지 추정 값에 맡기지 않는다.
- 무해한 접촉 그림자는 별도 shadow 파츠로 두고 과도한 포토리얼 질감 혼재 금지.

## 5. 무료 제작 루트

1. 무료 생성 환경(로컬 ComfyUI + 실행 가능한 공개 가중치/라이선스 확인)을 사용해 남녀 각각 기준 화풍 1명 제작.
2. 무료 Krita/GIMP로 마스터 정렬, RGBA 마스크, 헤어 및 옷 레이어 보정.
3. 기존 Python+Pillow 파이프라인에서 파츠 위치·알파·크기·접촉 그림자를 검사하고 2×2 조합을 완성.
4. 결함 발생 시 재생성 또는 수동 리터치; 샘플링 API 과금이 생기는 옵션은 기본값으로 사용하지 않는다.
5. 승인된 WebP만 ImageKit CDN 또는 무료 정적 호스팅에 게시. 사이트가 이미지 URL을 받지 못해도 기존 사진을 표시.

※ 로컬 무료 AI 생성은 충분한 하드웨어가 필요하다. 무료라는 말이 무제한 클라우드 GPU나 자동 미술 검수까지 보장하는 것은 아니다.

## 6. 게임 사용 원칙

- 목록·대화·관계: `view="bust"`.
- 인물/주인공 상세: `view="full"`; 승인된 full 그림이 없으면 **기존 초상화**로 폴백하고 그것을 전신이라고 표시하지 않는다.
- 사용자는 동일 인물로 만난 NPC가 보관되고 다시 등장해도 같은 faceId를 본다.
- 옷차림 변화는 outfitId만, 머리 변화는 hairStyleId만 변경; 새 이미지가 승인되기 전에는 잘못된 다른 인물로 바꾸지 않는다.
- 화면 성능: 목록엔 정적 WebP 썸네일, 상세만 큰 이미지. Canvas는 커스터마이징 미리보기에 한정.

## 7. 출시 QA 기준

- 16개 중 남녀/뷰 조합과 외모 정체성·헤어/의상 설계가 모든 이미지에서 일관.
- 고정 얼굴 코어는 픽셀 단위로 완전 일치(RGBA 원본 합성 기준).
- 색칠 필터/완성 사진 교체는 실제 파츠 교체로 인정하지 않는다.
- 명백한 목선/머리 경계 결함 0, 성별 태그 불일치 0, 미승인 조합 노출 0.
- 기존 세이브·수동 저장 가져오기·NPC 재등장에서도 얼굴 ID 고정.
- 실제 iPhone Safari에서 흰 화면·가로 넘침·깨진 리소스 없이 bust/full 뷰가 모두 표시.

**현재 시트 기반 16개 샘플은 이 QA를 통과하지 못했으며 게임으로 게시하지 않는다.**

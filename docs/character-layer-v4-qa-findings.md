# Nanal 실제 파츠 실험 v4 — 결과 및 출시 차단 보고

**날짜:** 2026-10-22
**상태:** 기술 합성 테스트 완료 / 16개 이미지의 미술 품질은 미승인 / 게임 적용 금지

## 기준 인물 잠금

- 여성 임시 앵커: 기존 `adult-female-v1` 얼굴 원본, 머리 묶음 기반 반실사 흉상.
- 남성 임시 앵커: 기존 `adult-male-v1` 얼굴 원본, 가르마 기반 반실사 흉상.
- 각 인물은 대체 얼굴을 로드하지 않고, 한 장의 원본과 분리된 alpha hair/back 및 outfit layer를 같은 좌표에 합성한다.
- 얼굴/전신 정식 마스터를 확정한 상태가 **아님**. 이전 앵커가 저해상도(원본 약 274px 가이드 크롭)이고 거의 정면이어서 최종 권장 약측면 10–15도와 차이가 있다.

## 실제로 제작한 것

- bust 8장: 남녀 2명 × 헤어 H01/H02 × 의상 O01/O02. H02는 기존 머리 위로 길이 있는 뒷머리 별도 투명 레이어를 추가함. **완전히 다른 앞머리/두상 헤어컷은 아님.**
- full 8장: 기술적인 인체 SVG와 동일 얼굴 원본의 크롭을 조합한 제작 기능 샘플. **반실사 전신으로는 불합격**.
- layer: 각 남녀 `identity_base`, `face_core_mask`, `hair_H2_back`, `outfit_O2` PNG.
- 16장과 파츠/원본/QA(JSON)를 묶은 로컬 비교 패키지 `Nanal_IdentityLocked_16_Technical_v4.zip`. 현재 게임에서 참조되지 않음.

## 확인한 기술 게이트

| 검사 | 결과 |
|---|---|
| 흉상 8개 변형의 원본 얼굴 핵심 ROI 동일성 | **통과** (여성 78,468px, 남성 76,862px × 각 4개, 변경 픽셀 모두 0) |
| 남녀 각각 실제 헤어 후면 **형태** 차이 | 기술상 통과 (긴 머리카락 부가 레이어) |
| 의상 실루엣/옷깃 형태 차이 | 기술상 통과 (별도 옷 그래픽 레이어) |
| 16개 최종 파일 수, 뷰 해상도 | 통과 |
| 16개 고품질 반실사 미술 품질 | **실패** |
| H02가 H01과 완전히 다른 머리컷 | **실패** |
| 1024×1536 정식 반실사 전신 원본 | **실패** |
| 실제 iPhone Safari 품질 검수 | 미실시 |

**핵심 구분:** 얼굴 중심 픽셀 동일성만 통과했다고 인물이 자연스럽다거나 16개의 게임용 외형 조합이 성공했다는 의미는 아니다. 실제 접합 경계·머리카락 리터치·의상 소재 텍스처는 미완성이다.

## 재사용 방지 / 품질 보호

- 게임 안에 16개 시안을 **게시하지 않는다**. `src/appearance.ts`의 승인 카탈로그를 비워둔다.
- `tools/validate_identity_pack.py`: Pillow/NumPy로 픽셀 및 크기·조합 차이를 검증. `--release`를 쓰면, 모든 8개 조합 쌍(총 16이미지)에 대한 사람 검수 `human-approval.json`, QA 보고서 상태 `APPROVED`, 각 16개 PNG의 SHA-256이 필요하다. 하나라도 없으면 실패 반환.
- 로컬 실험 원본이 GitHub에 업로드되지 않았어도 코드의 미승인 자산 폴백은 기존 초상화다.
- 승인 없이 자동으로 `approved: true`를 생성하지 않는다.

## 게임용 품질을 얻기 위한 남은 작업

1. 최신 콘셉트 스타일은 참고하되, **얼굴/전신 각각 처음부터 1024px/1536px의 실제 원본**을 만들고 남녀 같은 사람인지 확인.
2. 실제 다른 헤어컷 H02를 앞/뒤 마스크·귀 가림·그림자 포함 생산. 얼굴 마스터의 ROI 수정 금지.
3. 재킷·후드 등 O02를 기존 원본 그림에서 블록 도형을 덮는 방식이 아니라 실제 소재 텍스처, 주름·칼라·체형 맞춤 오버레이로 제작.
4. 두 뷰 간 얼굴, 머리, 의상 ID 일치 확인 및 전신 미술 QA.
5. 승인 16장 제작 이후에만 ImageKit에 업로드하고 NPC 앱 통합 테스트 실시.

**비용:** 유료 API 사용 없음. Python(Pillow/NumPy/추가 SVG 기술 목업용 CairoSVG)과 기생성 콘셉트 활용.

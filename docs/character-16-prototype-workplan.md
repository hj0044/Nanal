## 위험 및 경감

- **얼굴판/전신판 미세 불일치:** 동일 인물의 스타일 참고 원본을 고정하고 뷰별 별도 편집; human QA.
- **헤어·옷 경계:** 분리 마스크+접촉 그림자+앞뒤 레이어, 필요한 경우 특정 조합 재제작.
- **부정확한 무료/유료 약속:** 무료 도구 중심. 소요 시간을 줄이려 유료 API를 자동 호출하지 않는다.
- **이전 실패 UI 재발:** 완성형 사진 순환은 hairstyleId가 아니며, 사각형 염색은 outfitId가 아니다.
- **기존 게임 세이브 손상:** v1 저장/portraitId 그대로 유지, appearanceV2는 추가 필드만, 없거나 미승인이면 기존 이미지 반환.

## 결과물 품질 상태

초기 생성 콘셉트 시트에는 16개 조합 컷이 있지만 개별 원본 해상도 부족, 독립 파츠 PNG 부재, 완전한 얼굴 동일성 미확보로 **검증 불합격**.
이는 구체적인 미술 방향 참고물이며 16개 정식 스프라이트 완성을 주장하지 않는다.

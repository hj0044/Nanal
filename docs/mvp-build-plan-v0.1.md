- [x] 첫 주 생활 진행, 1·3·7일 진행 버튼, 이벤트/주간 정산에서 정지
- [x] 선택 결과를 수치·로그·관계에 반영
- [x] 브라우저 자동 저장 및 저장 파일 내보내기/불러오기
- [x] 60개 검토된 사건과 배경별 라이브러리
- [x] 주요 인물 12명, 눌러 여는 상세 프로필, 3단계 개인 서사
- [x] 관계·이벤트 반복 완화를 위한 최근 사건 기록과 쿨다운
- [x] 모바일 사진 비율 보정 및 NPC 초상화 ID 유지

- [x] 62개 초상화 카탈로그: 개별 얼굴 46명과 신규 아틀라스 얼굴 16명, 성별·나이 추정 범위 메타데이터
- [x] 저장 세이브마다 플레이어/NPC 초상화 ID 유지 및 기존 세이브 마이그레이션
- [x] 홈, 인물 목록, 상세 프로필에 동일 인물의 같은 얼굴 표시
- [ ] 작은 iPhone 화면에서 실기기 스크롤·노치·하단 탭 겹침 재검수
- [ ] 62개 얼굴 개별 QA 후 추가 인물 팩 확장

- [x] 하루 행동 선택(집중·휴식·교류·생활 정리)을 추가하고 에너지·스트레스·기분·집중도·관계에 반영
- [x] 오늘 행동은 하루 한 번만 적용하고 기존 저장 데이터에도 선택 기록을 선택적으로 추가
- [x] 사건 기본 발생률을 높이고 동일 사건은 우선 3주 쿨다운 후 재등장

- [ ] 일정이 긴 이벤트는 시간대·하루·주 단위 선택을 지원하고, 건너뛰기/되돌리기 UX 제공
- [ ] 인물의 기억 요약, 연락 빈도, 관계 변화 원인을 타임라인에서 확인

초상화 자산과 시각 QA는 별도 작업으로 관리한다. 현재 엔진 작업에서는 이미지 자산을 추가하거나 수정하지 않는다.

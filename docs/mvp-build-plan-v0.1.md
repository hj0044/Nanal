# Nanal 첫 플레이 프로토타입 구현 계획 v0.1

> 목적: 제품 방향 문서를 실제로 조작할 수 있는 작은 모바일 웹 프로토타입으로 검증한다.
> 상태: v0.1 최초 계획을 기록한 문서. 실제 구현 현황과 확정된 v0.2 설계는 [Nanal v0.2 첫 30분·NPC 명세](nanal-v0.2-first30min-npc-spec.md)와 검토용 PR에서 관리한다.

## 1. 저장소 확인 결과

- 저장소: `hj0044/Nanal`, 공개 저장소, 기본 브랜치 `main`.
- 이 계획서 작성 당시에는 짧은 README와 제품 방향 문서만 있었으며, 코드 구현은 시작 전이었다. 현재 브랜치에서 첫 주 플레이 프로토타입을 구현 중이다.
- 저장소 Pages 설정은 현재 비활성 상태로 확인됐다. 배포 전에 GitHub Pages 활성화와 배포 권한을 확인한다.
- 기존 제품 방향의 React·TypeScript·Vite 및 GitHub Pages 결정을 유지한다. 별도 호스팅 플랫폼이나 필수 유료 서비스를 추가하지 않는다.

## 2. 첫 프로토타입의 목표

캐릭터 설정부터 첫 주 선택, 선택 결과, 주간 요약, 저장 후 이어하기까지 끊김 없이 플레이할 수 있는 세로형 웹 게임을 만든다. 이는 한 달 이상 플레이를 목표로 하는 제품의 최종 범위가 아니라, 핵심 루프를 검증하기 위한 첫 시제품이다.

## 3. 플레이 흐름

1. 시작 화면에서 새 게임 또는 저장된 게임 이어하기를 선택한다.
2. 시작 연도(2020–2026), 시작 나이(19–30), 배경을 고른다. 첫 시나리오 배경은 대학생·취업준비생·직장인으로 한다.
3. 이름과 시작 설정을 직접 입력하거나 추천·무작위 설정을 받아 확인·수정한다. 지역·주거·가족 등 아직 정하지 않은 사실은 임의로 확정하지 않는다.
4. 선택한 설정을 반영한 짧은 도입 장면으로 시작한다.
5. 일주일 동안 상황에 맞는 사건 후보가 조건과 확률에 따라 나타난다. 큰 사건이 없는 조용한 주도 허용한다. 사건이 나오면 시간을 멈추고 상황과 2–4개 선택지를 보여준다.
6. 선택 결과는 현금·에너지·스트레스·관계·목표 등 관련 항목만 바꾼다. 화면에는 변화와 원인을 간단히 기록한다.
7. 주말 요약에서 한 주의 사건, 상태 변화, 다음 주에 이어질 일을 확인하고 다음 주로 진행한다.

## 4. 첫 시제품에 포함할 기능

- 스마트폰 세로 화면 우선의 생활 대시보드와 하단 5개 탭의 기본 골격
- 캐릭터 생성·추천/무작위 생성·시작 전 수정
- 대학생·취업준비생·직장인별 도입과 사건 데이터
- 조건 기반의 결정론적 난수 시드와 재현 가능한 사건·결과 처리
- 선택 후 자산·기분/에너지·스트레스·관계의 간단한 변화 기록
- 브라우저 로컬 자동 저장 및 새로고침 후 이어하기
- 설정의 테마 색상(기본/따뜻한/어두운) 및 자동 야간 테마 선택
- 민감 주제 기본 설정 구조. 해당 주제를 끈 경우 사건 후보·대사·후속 결과에서 함께 제외
- 세이브 내보내기·불러오기와 잘못된 파일에 대한 오류 안내
- 화면 낭독기와 키보드 조작을 고려한 기본 접근성

첫 버전의 확률은 데이터가 확보되기 전까지 임시 밸런스 값으로 명시한다. 현실 통계처럼 보이게 꾸며내지 않으며, 자료 출처·기준 연도 데이터가 준비되면 현실 데이터 모듈로 대체한다.

## 5. 구조 및 도구

- React·TypeScript·Vite 기반 정적 웹 앱
- 화면(UI), 게임 규칙/상태 엔진, 시나리오 데이터, 저장 기능을 분리
- 로컬에서 설치·검증 가능한 무료 도구를 우선하고, 필수 AI API·계정·백엔드는 사용하지 않음
- GitHub Actions에서 타입 검사·테스트·정적 빌드를 실행하고, Pages 활성화 후 정적 결과물을 배포
- 첫 구현은 `codex/mvp-first-week` 기능 브랜치에서 진행하고, 검토 가능한 Pull Request로 `main`에 제안

## 6. 첫 시제품에서 명시적으로 보류할 범위

- 한 달·일생 전체의 완성된 시뮬레이션
- 모든 NPC의 장기 자율 시뮬레이션과 망각·사망 모델
- 복잡한 연애·가족·기업 경영·투자 시스템
- 현실 통계 데이터베이스 전체 구축과 실명 기관 콘텐츠
- NPC별 고유 초상 이미지와 실사풍 일러스트
- 모든 사건의 분·시간 단위 진행과 대규모 사건 분기
- 멀티플레이, 계정, 서버 동기화, 유료 AI 연동

이 항목들은 삭제가 아니라 단계적 확장 대상이다. 첫 시제품에서 핵심 루프가 재미있고 이해하기 쉬운지 검증한 다음 넓힌다.

## 7. 검증 및 완료 기준

- 세 배경 모두 캐릭터 생성부터 주간 요약까지 정상적으로 진행된다.
- 사건이 발생하거나 발생하지 않는 흐름을 재현 가능한 시드로 검증할 수 있다.
- 선택이 게임 상태와 관계 기록에 반영되고 같은 세이브를 불러왔을 때 결과가 바뀌지 않는다.
- 새로고침 후 진행 복원, 세이브 내보내기·불러오기가 동작한다.
- 민감 주제 비활성 시 해당 주제가 사건·대사·후속 효과에 남지 않는다.
- 390×844 모바일 화면에서 주요 화면과 선택 버튼이 가로 넘침 없이 조작된다.
- 자동 검사와 빌드가 통과하고, 배포 전 사용자가 프로토타입을 확인한다.

## 8. 이후 확장 순서

1. 첫 주 프로토타입 플레이 테스트와 불편·지루함 수정
2. 첫 달 진행과 월말 정산 추가
3. 일·경제 및 생애·관계 통계 자료를 출처와 기준 연도 포함해 연결
4. NPC 자율 행동·관계 변화·기억 흐림을 단계적으로 도입
5. 프리랜서·창업자 배경, 더 많은 직업·지역·시대 확장
6. PWA 오프라인 개선, 초상·일러스트·세부 연출 고도화

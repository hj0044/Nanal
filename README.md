# Nanal

현대 한국의 인생 시뮬레이션 웹 프로토타입입니다.

## 실행

```sh
npm install
npm run dev
```

검사와 빌드:

```sh
npm test
npm run build
```

첫 프로토타입은 캐릭터 설정, 첫 주 생활 진행, 상황별 선택, 관계와 상태 변화, 브라우저 자동 저장 및 저장 파일 내보내기·불러오기를 포함합니다. 게임 내 수치와 확률은 플레이 검증을 위한 임시 값입니다. 현실 통계 자료는 출처와 기준 연도를 확인한 뒤 연결합니다.

제품 방향은 [docs/product-vision-v0.1.md](docs/product-vision-v0.1.md), 구현 계획은 [docs/mvp-build-plan-v0.1.md](docs/mvp-build-plan-v0.1.md)를 참고하세요.

## 캐릭터 얼굴 자산 승인 흐름

이전에 사용되었다가 폐기된 얼굴 자산은 게임 번들과 데이터베이스 썸네일에서 제거했습니다. 데이터베이스에는 폐기 여부를 추적할 자산 ID만 남기며 이미지는 보존하지 않습니다. 승인된 신규 초상화가 없을 때 게임은 인물 이름의 첫 글자를 기본 아바타로 표시합니다.

새 얼굴을 게임에 적용하려면 먼저 캐릭터 데이터베이스에 별도로 등록하고 검수해야 합니다. 승인된 이미지에만 새 ID를 부여한 뒤 `src/assets/character-portraits/catalog.json`에 `status: "approved"`와 `runtimeEligible: true`를 명시합니다. 승인이 없는 자산은 빌드와 자동 배정에서 제외됩니다. 기존 세이브를 불러오면 폐기된 초상화 ID와 해당 얼굴 변경 이력도 제거됩니다.

# Nanal

선택과 관계가 쌓이는 한국 인생 시뮬레이션의 첫 주 플레이 프로토타입입니다.

## 실행

```bash
npm install
npm run dev
```

## 검증 및 빌드

```bash
npm test
npm run build
```

첫 플레이에서는 대학생·취업준비생·직장인 배경, 첫 사건 선택, 주 2회 행동, NPC 자율 목표, 주간 정리, 브라우저 저장을 확인할 수 있습니다. 금액과 사건 확률은 임시 밸런스이며 현실 통계가 아닙니다. 자세한 설계는 [첫 30분·NPC 설계](docs/nanal-v0.2-first30min-npc-spec.md)를 참고하세요.
